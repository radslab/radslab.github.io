Features

Why RADYK

Built for developers who care about code quality, not marketing fluff.

Double Integrity

SHA256 for download verification, HMAC-SHA256 for boot-time file integrity. Two layers of protection.

Zero Bloat

No jQuery. No Bootstrap. Clean PHP, minimal JS, native CSS. Every file earns its place.

Extension Ready

Modular architecture with namespace isolation, auto-discovery, and per-extension integrity tokens.

PHP 8.2+

Modern PHP with strict types, enums, readonly properties, and first-class namespaces.

Multisite Safe

Network-wide activation support. Per-site isolation with shared configuration when you need it.

GitHub Powered

Releases, updates, and directory sync all via GitHub Actions. Zero server costs, zero maintenance.

Developer Experience

Clean by Default

Extensions ship with namespace isolation, auto-discovery, and built-in integrity verification.

register.json 
{
  "name": "seo-suite",
  "label": "SEO Suite",
  "version": "2.1.0",
  "integrity": "hmac-sha256:...",
  "settings": {
    "namespace": "SeoSuite\\",
    "autodiscover": true,
    "network": true
  }
}
